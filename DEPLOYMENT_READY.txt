📋 REQUIRED ENVIRONMENT VARIABLES
═════════════════════════════════════════════════════════════════════════════

You'll need these 5 values to add in Vercel:

  1. DB_HOST     = your-database-host.com
  2. DB_USER     = your_database_user
  3. DB_PASSWORD = your_secure_password
  4. DB_NAME     = pili_db
  5. DB_PORT     = 3306

Get these from your database provider (PlanetScale, AWS, etc.)

  • Keep .env file locally only (never commit)

  • Hardcode passwords in code
  • Share credentials in Git history
  • Expose database to public internet

🚨 MOST COMMON MISTAKES TO AVOID
═════════════════════════════════════════════════════════════════════════════

❌ MISTAKE 1: Forgetting to add environment variables
   → FIX: Go to Vercel Settings → Environment Variables

❌ MISTAKE 2: Using localhost as DB_HOST
   → FIX: Use actual database host (e.g., db.planetscale.com)

❌ MISTAKE 3: Committing .env file to Git
   → FIX: Add to .gitignore, only commit .env.example

❌ MISTAKE 4: Not setting DB_PORT
   → FIX: Add DB_PORT=3306 to environment variables

❌ MISTAKE 5: Wrong database password
   → FIX: Copy/paste from database provider, don't type
